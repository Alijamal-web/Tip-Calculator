# Tip Calculator

## About the Project

Tip Calculator is a simple command-line application developed using Python. It helps users calculate how much each person should pay when splitting a restaurant bill, including a selected tip percentage.

The program takes the total bill, tip percentage, and number of people as input and calculates the final payment per person.

## Features

- Calculates the tip based on a selected percentage.
- Splits the total bill equally among multiple people.
- Accepts user input for different bill amounts and tip percentages.
- Displays the final payment for each person.

## Technologies Used

- Python
- Built-in input() and print() functions
- Basic arithmetic operations

## How to Run

1. Clone or download this repository.
2. Make sure Python is installed on your computer.
3. Open the project folder.
4. Run the following command:

`python main.py`

## How to Use

1. Enter the total restaurant bill.
2. Choose a tip percentage (0%, 10%, 12%, or 15%).
3. Enter the number of people splitting the bill.
4. The program calculates and displays how much each person should pay.
